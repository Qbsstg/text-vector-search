## 必须保留的业务行为

- 空文本合法，20000 Unicode code points上限；渠道省略语义与严格Top-K保持。
- 原分数/负分/零分/后端排序保持，四位小数只显示；hitCount作为十进制字符串。
- 只有明确提交发起写请求；切Tab、查看详情、任务完成、失效不自动搜索；POST/PUT不自动重放。
- 202只表示接收；未知结果保留本次ID并按原ID核对，不自动换ID提交。
- 队列任务四态与文档有效性独立；原TaskTracker的3自动/2秒/60秒/20会话限制保持。
- 原文、摘要、ID和错误按纯文本显示；详情关闭/切文档的迟到响应不能复活或覆盖窗口。
- 提交/详情/确认弹窗可键盘关闭，焦点恢复；已失效不提供恢复，保留首次时间和历史快照。
- 公网health入口从普通页面移除，不开放或修改后端内部健康接口。
