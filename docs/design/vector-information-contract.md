# 文档规则与向量详情展示契约 v1.1

2026-10-27，Owner：主控。用户已选择双弹窗设计并明确要求开发上线。本轮范围仅为提交规则说明和已保存向量的只读详情、展开、复制；不是内容去重或新的业务接口。

## 保持的边界

六接口路径及原字段/状态语义保持；B1 算法、版本、codec、Top-K、DDL、任务状态机、事务和资源参数保持。按 ID 唯一，重复 ID 继续 409；不同 ID 的相同文本独立接收、统计与失效，不按指纹去重。原题未要求按原文去重，不能把项目的重复 ID 策略表述成原题明文。历史 FINAL_ACCEPTED、原始失败、测试数量与发布证据不改写。

## 响应扩展

`DocumentDetail` 新增可空 `vectorInfo`，字段为 `embeddingVersion,dimensions,byteLength,zeroVector,sha256,values`。仅详情 GET 装载实际向量；列表仍无向量，`TaskView.document` 保持轻量且 `vectorInfo=null`。

- 元数据、任务状态、版本和字节来自同一条 JOIN SELECT 快照，不修改全局列表/任务扫描列。
- 版本取 `documents.embedding_version`；指纹为持久化原始 1024 字节的 SHA256，64 位小写十六进制。不能对原文、舍入值或重新向量化结果计算。
- `dimensions=256,byteLength=1024`，`values` 包含全部 256 个有限 float32 数值，复用冻结 VectorCodec 解码；不截断为预览。
- 正/负零均视为数值零，指纹仍保留原始位。合法零向量完成后正常就绪，不能当“未生成”。失效文档继续可读历史向量。
- 未成功/未就绪为 null；坏字节、非有限值或已就绪却缺失必需存储元数据，使用既有 `500 INTERNAL_ERROR`，不泄露原件、不伪造成功或用 null 掩盖坏数据。
- 连接释放后解码/摘要；GET 不调用 TextEmbedder、不增计数、不写数据库或迁移。

## 页面和兼容

提交弹窗说明 ID 唯一、同文不同 ID 可提交并独立统计、同文同版本向量一致。详情按已选图分原文/元数据与向量信息两列，窄屏纵排。显示实际版本、维度、字节数、零向量及完整指纹；默认前8维六位小数，可展开256维。完整复制使用全部 float32 可往返精度，显式保留 `-0.0`，不能复制六位小数预览。

null/缺字段且未就绪显示“尚未生成”；兼容旧服务或任务轻量快照，就绪但未提供详情显示“服务未提供向量详情”。不硬编码假版本、指纹或终态。展开/复制仅本地操作，不发搜索/写入请求；外来文本使用纯文本，保留焦点/Esc和旧请求竞态保护。
