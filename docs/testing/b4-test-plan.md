## 分层与独立参考

1. **真实生产组成/HTTP层**：真实B1处理正常和空文，随机回环端口、每个用例独立绝对文件H2。保留此前DB_CLOSE_ON_EXIT生产默认，优先APP_DATA_DIR指定目录，不覆盖安全关闭参数。
2. **搜索组件/事务层**：直接公开构造器包裹真实Mapper/事务管理器，控制候选快照后、第二项增量前后、物理commit前后事件；测试方法不包外层@Transactional。外层真实事务误包装应明确拒绝或独立物理事务，不因测试事务未提交而误报200。
3. **数学边界层**：正向、反向、零向量夹具只证明零/负/同分/过滤边界；正常闭环仍须真实B1。独立参考不调用生产TopKSelector/其比较器生成期望；以人工精确方向向量和测试完整排序核对，真实文本只验证算法确定性，不预设语义相关性。
4. **并发层**：默认许可1的实际HTTP过载与测试高许可SQL并发分别计数，防止把串行请求“无丢失”当SQL并发证据。所有参与者barrier起跑，首请求持latch等全部拒绝结束再释放，不靠sleep猜重叠。
5. **网络/生命周期层**：计数已提交事件与HTTP断连顺序受控，RST或写响应故障是真网络事件，不能用一个普通业务异常代替。生命周期只杀/关自己的临时应用；不触服务器、不重复改B3历史强杀原件。

## 证据、事务未知与停止条件

- 按请求记录attempted / accepted / rejected429 / confirmedCommitted / confirmedRolledBack / outcomeUnknown；逐ID持久增量对账。未知结果不能强行归类为回滚或成功。
- 每次事件包含runId、源码SHA、线程、请求/文档标识与实际发生顺序。只提交小型合成数据说明，原始运行日志/报告走target及CI产物；真实失败原件需主控明确授权后单独归档，不覆盖B3旧证据。
- latch、barrier、Future、socket及子进程等待均有上限，finally释放自己的门闩、完成在途后再关H2；禁止无差别中断H2线程，不以随机sleep证明竞态。
- 未命中、非法请求、429、明确回滚、未知提交、HTTP断连分别保持状态与计数证据，不删断言或把期望改成当前错误行为。
- 遇真实缺陷先报告最小步骤/预期/实际/源SHA/原始证据，由后端修复，再独立复验。主控最终集成SHA需另做全回归。
