检索规则

确定性的字面特征算法不保证语义理解。余弦分数不是概率或置信度，零分和负分均保留；四位小数只用于显示，排序始终保持后端原始顺序。

空查询合法，将返回零分结果并正常计数；原始及规范化文本分别最多 20000 Unicode 码点。

仅明确提交表单才检索。查看详情、切换页面和失效均不自动检索；网络失败可能已计数，不自动重试。
